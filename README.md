# المحلّل الذكي للشخصية — تطبيق سطح مكتب (Tauri + React)

تطبيق سطح مكتب لتحليل الشخصية والانفعالات، بواجهة عربية RTL أنيقة بوضعين (فاتح/داكن).

## المتطلبات (لمرة واحدة)
1. Node.js 18+ : https://nodejs.org
2. Rust : https://rustup.rs
3. متطلبات Tauri لنظامك: https://tauri.app/start/prerequisites (على ويندوز: Microsoft C++ Build Tools + WebView2)

## المفتاح
انسخ `.env.example` إلى `.env` وضع مفتاحك:
```
VITE_ANTHROPIC_API_KEY=sk-ant-api03-مفتاحك
```
(محمي بـ .gitignore ولا يُرفع.)

## التشغيل
```
npm install
npm run dev            # تشغيل الواجهة في المتصفح (معاينة سريعة)
npm run tauri dev      # تشغيل التطبيق كنافذة سطح مكتب
```

## البناء النهائي (مُثبِّت)
```
npm run tauri build
```
تجد المُثبِّت في: src-tauri/target/release/bundle/

## ما المُنجز في هذه المرحلة
- هيكل الواجهة: شريط جانبي + شريط علوي + تبديل وضع فاتح/داكن.
- تبويب «التحليل» (صورة) يعمل فعلياً عبر نماذج Claude.
- تبويب «الشخصية»: استبيان OCEAN علمي + تقرير.
- تبويبات الفراسة/المقارنة/السجل/الإعدادات (هيكل جاهز + السجل الموحّد يعمل).
- طبقة ذكاء موحّدة تقرأ المفتاح من .env.

## المراحل القادمة
أوضاع الفيديو/الصوت/البث المباشر، ربط الفراسة بالمحرّك، لوحة المقارنة بالرسوم،
تشفير المفتاح عبر Tauri Stronghold، ثم الخادم الوسيط ونسخة الجوال (Tauri v2).
